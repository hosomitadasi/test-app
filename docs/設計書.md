# 設計書

## 1. 画面一覧

| 画面ID | 画面名称 | パス |
|---|---|---|
| PG01 | トップ画面（スマホの練習君） | `/` |
| PG02 | 会員登録画面（はじめての方の登録） | `/register` |
| PG03 | ログイン画面 | `/login` |
| PG04 | カギの作り直し画面 | `/forgot-password` |
| PG05 | メニュー画面（今日の練習） | `/menu` |
| PG06 | 練習内容選択画面（練習を選ぶ） | `/practice/contents` |
| PG07 | 練習詳細選択画面（画面操作の練習を選ぶ） | `/practice/details` |
| PG08 | 練習難易度選択画面（画面操作） | `/practice/difficulty/{type}` |
| PG09 | 練習画面（画面操作） | `/practice/play/{type}/{level}` |
| PG10 | 練習詳細選択画面（文字入力の練習を選ぶ） | `/practice/typing/details` |
| PG11 | 練習難易度選択画面（文字打ち練習） | `/practice/typing/difficulty` |
| PG12 | 文字打ち練習画面 | `/practice/typing/play/{level}` |
| PG13 | 練習難易度選択画面（チャット型練習） | `/practice/typing/chat/difficulty` |
| PG14 | チャット型練習画面 | `/practice/typing/chat/play/{level}` |
| PG15 | 成長の記録画面 | `/growth` |
| PG16 | これまでの記録画面 | `/growth/history` |

- `{type}`：tap / long / swipe / flick
- `{level}`：easy / normal / hard
- 練習詳細選択画面（PG07・PG10）と練習難易度選択画面（PG08・PG11・PG13）は、それぞれ同じ画面ファイルを使い回す。ボタンの名前・行き先・戻り先はコントローラーから渡す。
- 文字入力の練習は 練習内容選択 → 練習詳細選択（文字打ち練習／チャット型練習） → 難易度選択 → 練習 の順に進む。
- 会員登録とカギの作り直しは、どちらも1つの画面の中で段階的に進む（名前 → メールアドレス → 確認番号 → カギ）。

## 3. Model

| モデルファイル名 | 説明 |
|---|---|
| `app/Models/User.php` | 利用者。練習結果（practiceRecords）と獲得した称号（titles）を hasMany で持つ |
| `app/Models/PracticeRecord.php` | 1回ごとの練習結果（種類・難易度・得点・実施日時）。User に belongsTo |
| `app/Models/UserTitle.php` | 利用者が獲得した称号。称号の中身は `config/growth.php` の title_code で引く。User に belongsTo |
| `app/Models/VerificationCode.php` | メールで送った確認番号（会員登録用／カギの作り直し用） |

## 5. バリデーション

| バリデーションファイル名 | フォーム | ルール |
|---|---|---|
| `Auth/NameRequest.php` | 会員登録：名前 | name：required, string, max:50（前後の全角・半角空白は除去） |
| `Auth/EmailRequest.php`（共通の親クラス） | メールアドレス | email：required, string, max:255, not_regex:/[\r\n]/, email:rfc（全角は半角にし、空白は除去） |
| `Auth/RegisterEmailRequest.php` | 会員登録：メールアドレス | EmailRequest のルール ＋ unique:users,email |
| `Auth/ForgotPasswordEmailRequest.php` | カギの作り直し：メールアドレス | EmailRequest のルール ＋ exists:users,email |
| `Auth/VerificationCodeRequest.php` | 確認番号（会員登録・カギの作り直しで共通） | code：required, string, digits:6（全角は半角にし、空白は除去） |
| `Auth/PasswordRequest.php`（ルールは `Actions/Fortify/PasswordValidationRules.php`） | カギ（会員登録・カギの作り直しで共通） | password：required, string, min:8, max:255, regex:/[A-Za-z]/, regex:/[0-9]/, confirmed |
| `Auth/LoginRequest.php` | ログイン | email：required, string（全角は半角にする）／password：required, string |
| `StorePracticeRecordRequest.php` | 練習結果の記録 | practice_type：required, string, in:（`config('growth.practices')` のキー）／level：required, string, in:easy,normal,hard／score：required, integer, min:0, max:999 |
